# The Grief Navigator — Financial Bereavement Agent

**The Grief Navigator** is a proactive, AI-powered financial bereavement agent designed for the State Bank of India (SBI). 

When a customer passes away, their family is often left financially paralyzed—navigating nominee claim forms, FD transmissions, insurance claims, joint account freezes, and succession documentation while grieving. This platform detects death-adjacent signals from account activity and proactively reaches out to families with compassionate, step-by-step financial navigation.

## Key Features

1. **AI Signal Detection**: Autonomously detects bereavement signals (e.g., complete cessation of digital activity, condolence-pattern transfers, spikes in nominee queries).
2. **Succession Workflow Tracker**: Tracks the end-to-end pipeline of active cases, guiding nominees through identity verification, document submission, and insurance claims.
3. **Document Hub**: A central repository for processing and verifying critical documents with AI-assisted mismatch detection (e.g., name spelling variations on Aadhaar vs. PAN).
4. **Ethical Re-engagement Queue**: Identifies surviving family members 60–90 days post-settlement for gentle re-engagement, turning them into loyal SBI customers through a service rendered in a moment of need.

## Tech Stack

- **Frontend**: React, Vite, Tailwind CSS, React Router, Lucide React
- **Backend**: Node.js, Express
- **AI/LLM**: Simulated Agentic AI for natural language reasoning and ethical filtering
